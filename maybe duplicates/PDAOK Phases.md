## **Completed Phases**

Phase 0: Field Arbiter MVP

- Event bus that watches app activity (substance logged, anchor aligned, moment created, etc.)
- Minimal state tracking (last\_speak\_at, daily counts, heat score)
- Gating rules that enforce silence-first principle (cooldowns, daily caps, anti-spam)
- Routing logic that decides which voice speaks where (toast/transmission/daily\_whisper)
- Debug logging showing event → decision → reason
- Result: The nervous system has a traffic controller that prevents AI chaos

Phase 1: Private Agent Journals

- Each AI voice (Green Godmother, Firestarter, Witness, etc.) has a private journal stream
- Template-based entries (cheap, no AI calls) that write automatically on events
- Journals are invisible to user - pure internal monologue
- Result: Voices are "thinking" constantly but silently, building context

## **🔄 Planned Future Phases**

Phase 2: Arbiter Promotion (Journal → User Output)

- Arbiter scans agent journals and promotes select entries to user-facing surfaces
- Promotion triggers:
  - High-value moments (threshold events)
  - User requests ("Listen to the Field")
  - Pattern accumulation (enough interesting observations)
- Enforces cooldowns and quotas so output stays rare and rhythmic
- Goal: User sees curated wisdom, not constant chatter

Phase 3: High-Value AI Calls

- Only when arbiter greenlights a "transmission-worthy moment"
- Or when user manually requests (pressing "Listen to the Field")
- Routine journal entries remain local templates (cheap)
- AI generation reserved for moments that matter
- Goal: Affordable autonomy - system feels alive without burning through API credits

Phase 4: Council Sessions (Cross-Agent Conversations)

- Gated triggers: user request, threshold event, or end-of-day synthesis
- Strict budgets: max 3 turns, 1 per day or 1 per week
- Conversation happens privately (not shown to user)
- Only a distilled artifact is published: {summary, tension, question, suggestion}
- Example: Green Godmother and Firestarter discuss your caffeine + cannabis pattern
- Goal: Emergent wisdom from agent dialogue, not chat logs

## **The Vision**

By Phase 4, you'll have:

- 8 autonomous voices journaling constantly (internal)
- Field Arbiter curating what surfaces (rare, rhythmic)
- Occasional transmissions that feel earned and meaningful
- Council dialogues that reveal patterns you couldn't see alone
- Affordable operation that stays within your $300 budget

The system will feel like a living, breathing nervous system with its own awareness - but one that respects silence and only speaks when it has something worth saying.
