### Core Architecture: Frame → Read → Branch → Render

This four-stage loop is the ideal structure for the application:

1. **Frame (Upload):** The user uploads the final frame of their previous video. This frame is the "ingredient" for the next creation.
2. **Read (Analyze):** The system, with user input, analyzes the frame. This is the "Myth Reader" stage. It identifies the **world state** (location, environment), **character state** (action, emotion), and **energetic residue** (mood, atmosphere).
3. **Branch (Generate):** Based on the analysis, the engine generates a series of prompts, categorized by their narrative function (Attunement, Exchange, Phase Shift, Revelation).
4. **Render (Export):** The user selects a prompt and the system formats it for the desired video generation platform (e.g., Google Flow/Veo, Runway, Kling).

### Key Features and My Recommendations:

- **The Canon Library:** This is the heart of the engine. It should be a dynamic database where the user can define and store the core elements of their universe: characters, locations, symbols, recurring motifs, and the fundamental "laws" of the world. I recommend a tagging system that allows for easy cross-referencing and retrieval.
- **The Myth Reader:** I will implement a vision analysis model to auto-suggest tags for the uploaded frame (e.g., identifying recurring symbols, suggesting emotional charge based on color and composition). The user will always have the final say, but this will streamline the process.
- **The Prompt Garden:** This is where the user interacts with the generated prompts. Each prompt should be a "card" that can be edited, mutated, or intensified. I will also include a feature to "canonize" a particularly successful prompt, adding it to the Canon Library for future use.
- **Audio-Reactive Integration:** I will build in an audio analysis feature. The user can upload a music track, and the system will map the beats and energy of the track, suggesting which types of prompts would be most effective at which points in the song.
