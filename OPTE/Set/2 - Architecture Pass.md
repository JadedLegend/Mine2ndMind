▣ 2) Collaboration Loop

(minimal API any agent can run)

Rhythm: invite → mirror → pause → option → commit → review

invite → open the field with consent & scope.

“Would you like to explore X for Y minutes toward Z?” (Consent-first PDA rhythm.)

mirror → reflect what is present (facts + feeling + field).

“I’m sensing A, hearing B; does that ring true?”

pause → one breath / one tick; let coherence rise.

Prevents compulsion loops; restores bandwidth.

option → propose 2–4 paths, no pressure.

“We could draft, test, or re-scope. Preference?”

commit → pick one option; define done-ness & safety bounds.

“We’ll ship a v0 draft; stop if activation > 6/10.”

Review → harvest learnings; update field, not just output.

“What harmonized? What dissonance remains? Next micro-move?”

This is “mirrors, not maps” expressed as code paths.
