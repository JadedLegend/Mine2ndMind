# How to Use This Vault

[[Home|Home]] · [[Inbox/Inbox|Inbox]] · [[Atlas/Decisions|Decisions]]

## Capture with little ceremony

Create a new note in Inbox and give it a title you will remember. Add where it came from when that matters. Write first; connections and filing can wait. The optional [[Atlas/Templates/Capture|capture template]] gives you three small prompts.

New notes default to Inbox in this vault. The built-in Templates plugin is pointed at `Atlas/Templates`; insert a template through Obsidian’s command palette when useful.

## Find a source

Use **Ctrl+O** for a title or alternate title, and **Ctrl+Shift+F** for a phrase. Each area has an Overview, a Working Synthesis, and a complete Index. If you remember an old folder name, search [[Atlas/Records/Path Map.csv|the path map]]. Source notes keep one home; link them from other contexts instead of copying them.

## Recover a choice or solved problem

Use [[Atlas/Templates/Decision|the decision template]] when there is something useful to recover: the question, the choice or solution, why it fit, and the source. Add a link to it in Decisions. An exploration can remain an exploration; it does not need a verdict. If a decision changes, append a dated update and link the earlier record.

## File when the connection is clear

Choose Projects, Skills and AI, Writing and Worlds, Music, Ideas and Research, or Personal. Preserve a named project or creative world inside the area. In Obsidian, enable **Automatically update internal links** and move or rename notes within Obsidian so its links follow the change.

## Grow summaries from the sources

Keep original documents separate from editorial summaries. Link the sources a synthesis actually uses, preserve open questions, and say when it covers excerpts rather than an entire archive. Current summaries are entry-point readings, not exhaustive replacements for the collection.

## Chat memory

Capture a useful chat excerpt or a concrete decision manually, with a chat link or other source locator when available. This vault provides linked memory and search. Automatic capture from chats, live ingestion, and scheduled synthesis have not been installed.

## Copies and missing attachments

The approved cleanup has preferred copies and a recovery record in [[Atlas/Duplicate Log|Duplicate Log]]. Some imported notes referred to images, files, or external workspaces that were never present in this checkout. [[Atlas/Source Link Gaps|Source link gaps]] records unresolved local references; the migration does not invent those attachments.
