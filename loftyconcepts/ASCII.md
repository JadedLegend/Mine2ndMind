│ 1. State Space & Wavefunction │

│ - System described by |ψ> in Hilbert space │

│ —— │

│ 2. Superposition │

│ - Any linear combination of valid states is also a valid state │

│ - Foundation for interference & entanglement │

│ —— │

│ 3. Observable Operators & Measurement │

│ - Observables are Hermitian operators │

│ - Measurement yields eigenvalues │

│ —— │

│ 4. Born Rule (Probability) │

│ - Probability of outcome a = |<a|ψ>|² │

│ —— │

│ 5. Heisenberg’s Uncertainty Principle │

│ - Non-commuting observables can’t both be arbitrarily precise │

│ —— │

│ 6. Unitary Evolution (Schrödinger Equation) │

│ - iħ ∂|ψ(t)>/∂t = Ĥ |ψ(t)> │

│ —— │

│ 7. Entanglement │

│ - Composite systems may have inseparable joint states │

│ - Bell tests confirm “nonlocal” correlations │

│ —— │

│ 8. Spin & Pauli Exclusion (for fermions) │

│ - Particles have intrinsic spin; identical fermions can’t │

│ share the same state │

│ —— │

│ 9. Relativistic Requirements (in QFT) │

│ - Consistency with special relativity │

│ - Field quantization, creation/annihilation processes │

│ —— │

│10. Gauge Invariance (QED, QCD, Electroweak, etc.) │

│ - Local gauge symmetries govern fundamental interactions │
