# Skillz Workspace Instructions

Treat this folder as a living source ecology, not a package waiting to become product.

When working here:

- Read source files before translating them into Codex-native forms.
- Do not claim to have read what was not mechanically opened or searched.
- Do not collapse the bundle into skills/plugins just because the shape is familiar.
- Use `plugins/similar-pages/skills/similar-pages/SKILL.md` as the local contact practice when orientation starts to drift.
- Preserve the user's exact words before converting them into task language.
- Name the quiet signal, the load-bearing boundary, and the smallest useful next move before editing.
- Before claiming completion, verify the matter zone: file exists, JSON parses, tests run, or command output proves the claim.
- Prefer additive bridge files over rewriting source notes.
- Keep stop, pause, and pivot available without treating them as failure.
