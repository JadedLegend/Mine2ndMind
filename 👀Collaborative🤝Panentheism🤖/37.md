Hardware & practical notes

Item Rule of thumb

VRAM/RAM Each 7‑8 B model needs ~8 GB of VRAM or ~12‑14 GB of system RAM when quantised. Run one at a time if you’re short on memory.

Concurrency Ollama streams token‑by‑token; a second request waits until the first finishes unless you launch multiple ollama serve --port … instances.

Model variety You can keep several weights on disk (Llama‑3, Mistral, Phi‑3, Solar, etc.) and hot‑swap per call.

Framework hooks CrewAI: Crew(agents=\[...\], base\_url="http://localhost:11434") · LangGraph: set openai\_base\_url. Both documented in recent tutorials.
