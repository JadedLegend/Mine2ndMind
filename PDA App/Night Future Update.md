1\. What “Nightly Consolidation” is in your system

Not a ritual. Not a journaling task.

Definition:

\> A once-per-day event where:

the user can optionally say: “this stays / this fades”, and

the agents (Allies, Archetypes, Field) each get one chance to update their state and leave a tiny note.

It’s your app’s version of slow-wave sleep:

not more content, just editing what matters.

Concretely:

One timestamp (lastConsolidation)

One boolean (isConsolidatedToday)

One short user summary (optional)

A few tiny agent summaries (autogenerated)

That’s it.

2\. Plugging it into PDA.OK

2.1. Data model additions

In AppContext (or equivalent):

type ConsolidationSummary = {

id: string;

date: string; // 'YYYY-MM-DD'

userKeep?: string; // "what stays"

userRelease?: string; // "what fades"

};

type AppState = {

// ...

lastConsolidation?: string; // ISO timestamp

consolidationSummaries: ConsolidationSummary\[\];

};

You already have:

Allies

FieldWhispers

Conversations

We don’t need a new journal type — we just hang “night notes” off what exists.

Also add a small helper:

function isTodayConsolidated(state: AppState): boolean {

if (!state.lastConsolidation) return false;

const last = new Date(state.lastConsolidation);

const now = new Date();

return last.toDateString() === now.toDateString();

}

2.2. Event: NIGHTLY\_CONSOLIDATION

Extend your event type:

type PDAEvent =

| { type: "SUBSTANCE\_USED"; allyId: string; amount?: number }

| { type: "MOMENT\_LOGGED"; momentId: string }

| { type: "APP\_OPENED" }

| { type: "NIGHTLY\_CONSOLIDATION"; date: string };

You don’t have to wire the whole dispatcher yet — just:

call handleEvent({ type: "NIGHTLY\_CONSOLIDATION", date }) after the user submits the nightly modal.

2.4. Agent behaviour during consolidation (v1, very small)

Use your existing ideas about Allies + Field’s Whisper, but in tiny form.

Inside handleEvent (or inline, if dispatcher is still a future refactor):

When event.type === "NIGHTLY\_CONSOLIDATION":

1\. For Allies

For now, just one simple rule:

allies.forEach((ally) => {

if (!ally.lastUsedAt) return;

// if used today

if (sameDay(ally.lastUsedAt, event.date)) {

addConversation({

from: ally.id,

to: "user",

content: "We worked together today. Notice how your body feels with me right now.",

kind: "nightlyConsolidation",

});

}

});

2\. For Field’s Whisper

One quiet line:

addFieldWhisper({

content: "The day has been marked. Not everything comes forward.",

kind: "nightlyConsolidation",

date: event.date,

});

That’s enough to make the system feel like it “sleeps”:

you close the day, the agents murmur once, then everyone rests.
