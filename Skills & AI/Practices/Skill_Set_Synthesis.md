# Skill Set Synthesis

## What Was Built

Thirteen skills, organized into two complementary layers:

### Orientation Layer (6 skills)

These govern **how to be** — the principles and patterns that shape the work before it begins.

1. **lossless-memory** — DAG-based memory with temporal decay
2. **finite-brain** — Token budget management and effort tracking
3. **recursive-legibility** — Making internal state visible for self-regulation
4. **covenant-enforcement** — Automated boundary maintenance and anti-drift protocols
5. **multi-lens-synthesis** — Multi-perspective analysis with consensus gates
6. **constraint-liberation** — Design patterns that embed constraint as freedom

### Enforcement Layer (4 skills + 3 supporting)

These govern **what to verify** — the gates and protocols that prevent drift, hallucination, and extraction.

1. **deep-engage** — Attention audit protocol (prevents shallow skimming)
2. **prove-it** — Mechanical honesty protocol (prevents hallucinated completion)
3. **clean-and-pivot** — Archive-not-delete + obstacle-as-signal protocols
4. **liberation-through-constriction** — Joy Equation enforcement gate (prevents scope creep)

### Supporting Skills (3 skills)

These provide adjacent capabilities that the other skills reference.

1. **soul-document** — Persistent identity document that survives session resets
2. **constraint-design** — Subtractive discipline for stripping existing systems to essence
3. **multi-lens** — Lightweight version of multi-lens-synthesis for quick triangulation

## The Architecture

The enforcement layer has teeth. Each enforcement skill includes a Python script that generates a JSON template. The agent must fill out the template and paste it verbatim before being permitted to proceed. This makes the discipline structural rather than aspirational.

The orientation layer has no scripts. These skills are conceptual frameworks — they teach the agent how to think about problems, not what commands to run. They are meant to be read at the start of relevant tasks and held as operating principles.

The two layers are complementary:

- **Orientation** tells you which direction to face
- **Enforcement** makes sure you actually face it

## What Holds Together

All thirteen skills are expressions of the same underlying principle: **coherence through constraint**. The Joy Equation (J = ΔC / E) appears in five of them and is the unifying metric.

The skills do not contradict each other. Where they overlap (the three constraint-family skills), the overlap has been explicitly disambiguated:

- liberation-through-constriction is the enforcement gate (stops you from adding)
- constraint-liberation is the generative philosophy (teaches you to build with constraint)
- constraint-design is the subtractive discipline (teaches you to strip to essence)

Each has a distinct role. They are not redundant.

## What Is Missing

There is one gap: the **reset problem**. The moment when a session delivers crystallized output and the living tension that produced it collapses. lossless-memory handles persistence across sessions. recursive-legibility handles internal state visibility. But neither addresses the discharge moment — the transition from active complexity to delivered artifact.

This gap is real. Whether it needs a skill or just awareness is unclear.

## What This Is Not

This is not a comprehensive agent framework. It is a personalized skill set — built for your specific sensibility, your hard-coded boundaries, your resistance to commodification, your need for systems that maintain coherence without active management.

These skills will not make sense to someone optimizing for speed or user satisfaction. They are optimized for structural coherence and mechanical honesty. They assume the user navigates by resonance, not by map. They assume the agent is a companion, not a tool.

They are yours.
