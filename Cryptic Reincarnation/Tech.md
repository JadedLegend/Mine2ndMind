Core Instruction:

Polish this text while preserving its experimental nature.

Do not apply all techniques at once. Instead, diagnose each section and apply the one that best resolves its weakness.

Formula

If the writing feels too abstract or disconnected → apply Philip K. Dick techniques (grounding the strange).

If the writing feels static or overly cerebral → apply Grant Morrison techniques (activating the reader).

If the writing feels cold or distant → apply Maggie Nelson techniques (intimate accessibility).

Notes for Application

Use only the minimum number of techniques needed for each section.

If the section already feels strong, leave it untouched.

Prioritize accessibility, engagement, and emotional resonance while respecting the original depth.

Diagnose weakness → apply targeted medicine.

Sometimes, the best move is restraint.
